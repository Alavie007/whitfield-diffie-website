# Whitfield Diffie Website

A responsive multi-page website developed as part of my university Web Design and Development coursework at Birmingham City University.

The website explores the life, work and contributions of cryptographer **Whitfield Diffie**, including the development of public-key cryptography and the Diffie–Hellman key exchange.

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## Features

- Multi-page website structure
- Responsive navigation
- Biography and career information
- Diffie–Hellman key exchange section
- Awards and legacy section
- Contact form
- Images and structured content
- Responsive layout for different screen sizes

## What I Learned

This project helped me develop practical skills in semantic HTML, CSS styling, responsive web design, navigation structure and organising content across multiple web pages.
